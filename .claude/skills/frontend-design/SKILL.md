# 前端设计规范 —— 执行手册

**权威来源:`tile-ai-design.md`(仓库根目录)。**
本 Skill 只是它的执行清单,**不产生新规则**;两者冲突时,**以 `tile-ai-design.md` 为准**,
并顺手把本文件改回来。

---

## 铁律(动手前先记牢)

1. **颜色 / 间距 / 圆角 / 字号一律走 CSS 变量** —— 令牌只在
   `tile-ai-web/src/styles/tokens.css` 定义。
   业务代码里**只准出现 `--color-*` 语义令牌**,不准出现 `--stone-*` 之类的原始色板,
   **更不准出现十六进制色值**。
2. **antd 只准通过 `a-config-provider` 的主题令牌着色**(集中在
   `src/styles/antdTheme.ts`)。出现 antd 默认蓝 `#1677ff` = 缺陷。
3. **页面不得直接 `import` antd 组件** —— 全走 `src/components/` 包装层。
   ⚠️ **当前的例外(2026-10-03)**:阶段 G1 的试点页(`AdminProductEditView`)是**直接 import**
   的 —— 那是刻意的,为了用最小代价先验证"antd 在这套主题下好不好看"。
   **包装层要不要建、建到什么程度,是 G1.5 的决策**(见 `openapi-verification.md` §68.5)。
   **G1 之外的页面不要照抄这个例外。**
4. **C 端和 B 端是两套主题**(`data-theme="site"` / `"admin"`)。
   品牌色(陶土)两端统一;差异在密度、圆角、留白、图片占比。
   **别把一个端的样式复制到另一个端。**
5. **图是主角,但参数与报价必须同屏**:定位是**装修工具**,不是杂志。
   有图的地方图占最大视觉权重,但**关键参数、规格、报价不得藏进二级页面 / 折叠面板**。
   图片一律**固定宽高比 + 懒加载 + 骨架屏 + 失败占位**。
6. **危险状态不得只靠颜色区分** —— 危险色与主色同为暖红系,必须配图标或文案。
7. **金额必须可信**:右对齐、`tabular-nums`、单位与小数位统一,用 `PriceText`。
8. **先读场,再动版面**:动手前先用**一句话**说清「这一页服务**谁**、他**此刻**要干什么、
   成功后他**下一步**去哪」,并**写进登记表**(`tile-ai-design.md` §2.1)。
   **读错了场子,后面的配色与间距全是白做。**
9. **动效按标尺选档,且必须能降级**:时长只能取 `--dur-fast` / `--dur-base` / `--dur-slow`
   三档之一,**按用途选**(§3.10:反馈 120 / 进出 200 / 大块 320);
   不许超过 400ms、不许无限循环、不许回弹缓动;
   且**必须能被 `prefers-reduced-motion` 降级**(§3.11)。

## 动手前

- [ ] **先用一句话写清「设计读场」**(§2.1):这一页服务谁、他此刻要干什么、下一步去哪。
- [ ] 对照 **§2.2 的禁止清单(AI Tells)**过一遍 —— 尤其别撞"三张等大的功能卡"
      "到处玻璃拟态""无限循环动效"这些**一眼就是 AI 生成的**套路。
- [ ] 读 `tile-ai-design.md` 里跟本次改动相关的章节(令牌看 §3,双主题看 §4,
      antd 看 §5,组件看 §6,响应式看 §7,改造边界看 §8)。
- [ ] 确认这次改的是 **C 端还是 B 端**,取对应主题。
- [ ] 若是**新页面 / 新组件**,先看 `src/components/` 有没有能复用的原语。

## 提交前

- [ ] `grep -rn "#[0-9a-fA-F]\{3,6\}" tile-ai-web/src` —— 只该命中
      `tokens.css` 与 `antdTheme.ts`。
- [ ] `grep -rn "1677ff" tile-ai-web/src` —— **零命中**。
- [ ] 业务 `.vue` 里没有直接 `import { ... } from 'ant-design-vue'`。
- [ ] 改动的数据区有 **空 / 加载 / 错误** 三态。
- [ ] 动效时长取自 `--dur-*` 三档,且**按 §3.10 的用途表选**;
      **无无限循环、无回弹缓动、无 >400ms**。
- [ ] 新增的动效**能被 `prefers-reduced-motion` 降级**(§3.11)。
- [ ] 改了页面结构 ⇒ **同步重写该页的测试**(`tile-ai-web/tests/`),
      **不许靠删断言迁就**。
- [ ] `cd tile-ai-web; npm run test; npm run build` 通过。

## 常见误用(会踩的坑)

| 想干的事 | 别这么干 | 该这么干 |
| --- | --- | --- |
| 让按钮变主色 | `style="background:#B4552F"` | 用 `AppButton` + `--color-primary` |
| 调 antd 某组件颜色 | 页面里 `:deep(.ant-btn){…}` 或 `!important` | 改 `antdTheme.ts` 的主题令牌 |
| B 端表格太松 | 页面里逐个改 padding | 用 B 端主题(`compactAlgorithm` + 收紧间距) |
| 图片加载时页面跳 | 直接 `<img>` | 固定宽高比容器 + 骨架屏 |
| 给个错误提示 | 只标红 | 红色 **+** 图标 **+** 文案 |
| 想让页面"高级" | 把报价 / 参数收进折叠面板 | 保持**参数与报价同屏**(工具定位) |
| 加个动效 | 随手写 `transition: all .3s` | 取 `--dur-*` 三档,**按 §3.10 的用途选** |
| 动效想"活一点" | 用回弹缓动 / 无限循环 | 一律 `--ease-standard`;**循环只留给"正在加载"** |
| 页面显得空 | 加三张等大的功能卡 | 先读场,再按**信息层级**排(§2.2 禁止清单 A) |

## 边界(别顺手做)

- 不做**暗色模式**、不引 **web font / 图标库 / 第三方动画库**、不做**移动端深度适配**、
  不做**国际化视觉** —— 都在 `tile-ai-design.md` §11 明确推迟。
  ⚠️ **但「组件自带的过渡」不在禁止之列**(2026-10-03 精确化):antd 组件的出入场动效、
  Vue 内置 `<Transition>` / `<TransitionGroup>` 都算"**用已有能力**",不算"引一个库"。
- **分享预览卡片(OG / SSR)是独立工作流**(`tile-ai-design.md` §7.1),不归本 Skill 管,
  别顺手在样式改造里做。
- 本 Skill **不碰接口/字段**。要改契约,回 `CLAUDE.md` 的契约链规矩走。
